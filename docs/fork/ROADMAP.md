# 开发路线图（Roadmap）

> 更新：2026-10-04 ｜ 依赖顺序与并行关系见文末。

## MVP = M0 + M1 + M2 + M3

| 里程碑 | 目标 | 关键实测结论 | 依赖 | 粗工期 |
|---|---|---|---|---|
| **M0** 底座验证 + 角色包 | 跑通 Windows 基线；换成王梦诗形象 | 换 VRM **免改代码**（Asset Pack） | — | 3~5 天 |
| **M1** 人设 + 中文语音 | 王梦诗御姐人设 + CosyVoice 中文音 | 语音配置已在（`speechMode`/`recognitionMode`）；AILIS 身份写死 "AILIS"，单角色阶段先替换 | M0 | ~1 周 |
| **M2** 感知 + 免打扰 | 键鼠 idle / 前台应用 / 全屏 / 免打扰 | **AILIS 完全无 OS 级感知 → 基本从零建**（新建 `electron/ailis-user-presence.cjs` + IPC + 扩展主动管理器门控） | M0 | ~1~1.5 周 |
| **M3** 行为引擎 + 脾气 | 可插拔行为引擎 + 藏/挪图标、假垃圾桶、吐槽、提醒 | `behavior-scheduler.js` 只是骨骼微动，**非行为引擎 → 从零建**；桌面动作**复用** `ailis-computer-tool.cjs`（审批/审计/恢复） | M1,M2 | ~2 周 |
| **M4** opencode 桥接 | 事件流（显示器）+ 指令（遥控器）+ MCP | **零集成 → 从零建**；复用 Gateway `EventEmitter` + **SSE `/events`** + 现成 MCP 客户端 | M0 | 1~2 周 |
| **M5** 情绪 + 打磨 | 脾气随心情变化、稳定常驻 | **情绪管线已存在 → 改为扩展**（抽写死枚举为角色配置） | M3 | 1~1.5 周 |

## 横切轨道
- **R7 多角色命名空间化**：记忆库 / persona 渲染器 / 主动管理器 / character-runtime 均写死单角色 "AILIS" → 贯穿 `characterId`。**必须改 core**，在 M0/M1 单角色跑通后启动设计，增量落地。
- **许可合规**：见 `asset-licenses.md`，收费/分发前必过。

## 依赖与并行
```
M0 ─┬─> M1 ─┐
    ├─> M2 ─┴─> M3 ─> M5
    └─> M4   (独立)
R7: M0/M1 跑通后启动设计
```

## 非目标（明确不做）
不做启动器／不真删文件／首版不做移动端／不做多人云同步／不做直播推流／不追求"完美助手"。

## 形象轨道（一角色多版本）
| 阶段 | 内容 | 状态 |
|---|---|---|
| **A0** | 占位：仓库自带 AiGril 验证换脸链路 | ✅ 完成 |
| **A1** | **动漫风**王梦诗（VRoid + AI 脸部贴图/InstantID） | 进行中（先做） |
| **A2** | **3D 写实**版（Ready Player Me / Avaturn → Blender VRM 转换） | 后续（一角色两版） |

## NSFW / 18+ 轨道（后续，见 [NSFW-PLAN.md](NSFW-PLAN.md)）
- **N0** 18+ 开关与门控骨架 → **N1** uncensored 模型接入 → **N2** NSFW 资产 → **N3** 成人人设。
- 占位原则：**关闭即拒绝**；资产本地隔离、不进公开仓库、不分发。

## 语音轨道
- **V0** 现用 hosted TTS（可用，有延迟）——当前状态。
- **V1**（B2）CosyVoice3 本地 TTS（~11.7GB 构建）——排在形象/主链路之后。

## UI 轨道（角色名动态化，R7 第一步）
- **UI-1** ✅ 界面显示的角色名**跟随当前角色包**：聊天标题/输入框占位、控制面板标题、桌宠气泡标签、右键快捷面板 → 从 `characterAssets.effective.displayName` 注入（默认 AILIS；王梦诗包→"王梦诗"）。机制：`i18n.js` 的 `setCompanionName()` + `{name}` 占位符。
- **UI-2**（待办）控制面板说明性文案里的 "AILIS" 一并动态化。
