# 王梦诗 形象方案（动漫版优先）

> 路线：VRoid Studio 手工建造（所有者操作）→ 导出 VRM → 安装验证。
> 后续：AI 锁脸增强、3D 写实版（详见文末）。

## 0. 参考风格（依据本人照片）
- **发型**：黑色短发 bob，齐下巴/齐耳，**薄齐刘海**，发尾微碎。
- **眼镜**：**细金属圆框**。
- **脸**：冷白皮、深色眼、清冷中性、眼神冷静。
- **气质方向**：冷静克制、略带疏离 → 对应"外壳高冷/腹黑、内里温柔"的**御姐**。
- **穿搭（可选）**：简约休闲街头（黑白 T、oversize 外套、金属细饰）。

## 1. 前置
- VRoid Studio **2.14.0**（已安装）。
- 新建角色 → 体型选**成年女性**。

## 2. 身体（Body）
- 身高：约 **165–170**；头身比取**成熟**（略高、腿长）。
- 体型：偏瘦；腰细、腿长；胸/腰/腿勿过度夸张。
- 肤色：**冷白**（色板偏冷、明度高）。

## 3. 脸部（Face）
- 脸型：**成熟/偏长**；下巴**略尖略收**；脸颊**内收**（显瘦）。
- 眼睛：**上挑杏眼**；眼型细长；双眼皮偏窄；眼白冷调。
- 瞳孔：**深棕/近黑**；高光小、冷。
- 睫毛/眼线：**细、上挑**，淡妆。
- 眉毛：**平直略上挑、深灰近黑**，不宜粗。
- 鼻子：小巧、鼻梁挺。
- 嘴：小巧；**唇色裸粉/豆沙**；嘴角平（冷感）。
- 妆容：**淡**（冷调眼影 + 淡唇），避免浓妆。

## 4. 发型（Hairstyle）
- 预设：选**短发 bob（齐下巴）**类；无则取短直发调短。
- 刘海：**薄齐刘海**。
- 发色：**近黑**（#1a1a1a ~ #202020）。
- 发尾：略碎；侧发至下颌。

## 5. 眼镜（关键难点）
VRoid 无原生"眼镜"分类，二选一：
- **方案①（推荐）饰品导入**：`饰品(Accessory)` 页导入**圆框眼镜 OBJ**。免费来源：Booth 搜 `VRoid 眼鏡/メガネ`、VRoid 官方素材、VRoid Hub 配件。
- **方案② 贴图占位**：在脸部/眼镜贴图上手绘圆框（先能看，后续换 3D 眼镜）。
- （可选）可代为生成**简易圆框眼镜 OBJ**（双圆环 + 鼻梁桥 + 镜腿），需你在 VRoid 里定位/缩放。

## 6. 服装（Outfit）
- 先用内置简约款（T 恤/外套），配色黑/白/灰；后续再换装或做服装资产。
- 饰品：细项链/戒指可选（Accessory 导入或忽略）。

## 7. 导出与安装
- 格式：**VRM 1.0**。
- 文件名：**`model.vrm`** → `D:\program\desktop-ai-companion\characters\mengshi\assets\model.vrm`。
- 权限：个人私用/保守设置（详见素材许可审计）。
- 完成后：我重装 `characters/mengshi` 角色包并验证渲染。
