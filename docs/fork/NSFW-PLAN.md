# NSFW / 18+ 支持方案（规划，暂不实现）

> 状态：**规划中，实现排后续**（先整体跑通非 NSFW 主链路）
> 决策：先在控制面板加"18+ 开关"的**机制**；具体**露骨内容由所有者提供**，开发侧不代写。

## 1. 目标
- 控制面板提供 **18+ 开关**（默认关）。
- **开启时**：使用 uncensored 模型 + 成人模式人设 + NSFW 资产。
- **关闭时**：使用当前模型，并**拒绝**成人内容。
- 全部**本地**运行；NSFW 资产与对话**不进公开仓库、不分发**。

## 3. 技术方案（机制）
1. **配置**：`electron/store.cjs` 增偏好 `nsfwEnabled`（bool，默认 false）+ 可选 `nsfwLevel`；`control-panel` 加开关（含年龄确认提示）。
2. **人设门控**：`nsfwEnabled` 为真时，向系统提示注入"成人模式"人设片段（文本由所有者提供）；否则不注入。
3. **模型切换**：`nsfwEnabled` 为真时，AILIS 的 Ollama 模型指向 uncensored 模型（`ollamaModel` 切换）；否则用日常模型。
4. **资产加载**：NSFW VRM 作为独立 `character_pack`/`skin_pack` 变体；通过 AssetPack 机制加载；目录加入 `.gitignore`，**永不提交/分发**。
5. **拒绝路径**：关闭时，成人请求走正常模型（会拒绝）并在 persona 层明确不配合。

## 4. 硬件约束（实测）
- RTX 3070 Ti **8 GB**：uncensored 7~8B **Q4_K_M**（~4.5GB）+ ctx8192 ≈ 5.5–6GB，**可行**。
- **两个 LLM 不能同时驻留**：Ollama 按需换入换出（切换有短暂加载）。
- 若同时要 NSFW 形象 + 语音，注意显存调度（语音走 CPU/云或后续 CosyVoice）。
